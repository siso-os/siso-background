# art/

Images we made before the code version, kept as references and shown on the asset page. Assets never load them.

- `isles/`: the SISO Isles photo art from SISO's desktop theme: city
  plates (4 cities x 4 lights), cut-outs (the SISO tower, 3 floating islands, 6 buildings, 4 boats), prompts in
  `isles/PROMPTS.md`, list in `isles/manifest.json`. Made with image generation for SISO.
- `isles/marina/` and `isles/fx/`: from github.com/alj04ofm-svg/ALJ-HERDR-WEB-UI, MIT; their LICENSE files sit beside them.

The new reference paintings live in `refs/` (see `refs/manifest.json`).
